Public repositories, and why they exist.

Each one came out of Rivenside’s research, and the code is open for anyone to check.

  • Rivenside AI Planner

    Tool · MIT

    An AI project planner. It interviews you, documents your project, checks it for gaps and contradictions, and writes a build plan before any code exists.

    Why it was made
    Made to build small projects quickly, without AI losing track of a project as it grows. The planner moves a project's context out of the conversation and into documents, so each step of a build can be done without relying on memory.
    Built with
    Markdown, Claude Code

    GitHub ↗ The research

  • Sunrune

    Demo · MIT

    Chapter 1 of a top-down story RPG that runs in the browser. About 8 to 12 minutes, title screen to credits.

    Why it was made
    Built from one simple prompt with the Rivenside AI Planner and no interference, to see how much AI can build on its own. It took about 8 hours and 5 USD in tokens.
    Built with
    JavaScript, Canvas 2D, Web Audio

    GitHub ↗ Play ↗ The game The research

  • Rust Country

    Demo · MIT

    A single-level browser platformer in the spirit of Donkey Kong Country. One HTML file, no dependencies.

    Why it was made
    Built from a single prompt, with no human intervention, to find the ceiling of what one prompt can produce.
    Built with
    HTML, JavaScript, Canvas 2D, Web Audio
