    Pixel Game Lab

    A specialised AI system for generating complete 2D pixel art RPGs from a single sentence prompt, including the world, characters, story, mechanics and game flow.

    I’m building it around the idea that AI can create detailed, atmospheric game worlds and stories when given the right assets and a system designed specifically for game development.

    Sunrune was an early experiment using the current system I built, applied with Claude Opus 5. I gave it a single sentence prompt and a set of Kenney assets, and it produced the game. The demo was built in about eight hours and cost roughly $5 in tokens.

    The experiment worked, so I’m now making the system more specialised and detailed, with the goal of generating complete games from start to finish. I’m also working toward running it locally, so I can create games without paying for online AI services each time and make games that fit the stories, worlds and characters I want to play.

    Future versions will also give certain characters their own AI brains, allowing them to make decisions and react to the world independently.
