Commitment

This website aims to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

What’s been done

  • Text and interface colours meet WCAG AA contrast in both the light and dark themes, and this is checked automatically.
  • The site follows your system’s light or dark setting, and its text scales with your browser’s text size.
  • Everything can be used with a keyboard, with a visible focus indicator throughout.
  • A “Skip to content” link is the first thing on every page.
  • Pages use landmarks and a logical heading order.
  • Links in running text are underlined, so they don’t rely on colour alone.
  • If your system asks for reduced motion, animation is turned off.

Known limitations

Smooth page-to-page transitions use a browser feature not every browser supports yet; where it isn’t supported, pages simply load normally.

Reporting a problem

If something here is hard to use, email mohsinmkhan676@gmail.com with the page and what went wrong.
