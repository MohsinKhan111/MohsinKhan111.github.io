Services

  • Web and app development

    Mainly websites, web apps and apps, plus smaller pieces of software, from the first build to launch.

  • Backend and database management

    Databases, backend services, APIs, authentication and data infrastructure, on platforms such as Supabase, Firebase and AWS.

  • Server and infrastructure management

    Server configuration, deployments, hosting, DNS, monitoring, backups, security updates and ongoing maintenance.

  • AI consulting and research

    Practical help with prompt engineering and with how models keep context across a project, based on Rivenside’s own experiments. The underlying concepts are an area of active study. Open to research collaboration in these areas, and in AI safety.

  • 2D pixel art games

    Helping beginners build complete 2D pixel art browser games in very little time, with tailored repositories and guidance on using them to create worlds, characters, stories and full RPGs.

  • IT services

    Office and network setup, devices, backups, and day-to-day technical support for small and medium businesses.

  • Hardware prototyping

    Hardware I do for fun. If the project is interesting, I’ll do it for free.
